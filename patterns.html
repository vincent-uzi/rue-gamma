❄️ Snowflakes — composants non mutualisés

Composants inline uniques ou quasi-dupliqués qui mériteraient d'être rationalisés en Phase 2.

#1 — Deux verts incohérents Impact H
#1F9D55 utilisé 73× ET #00A651 quelques fois — incohérence visuelle subtile mais réelle.
→ Fix : --brand-green: #1F9D55 en CSS variable
#2 — 6 façons d'ouvrir une modale Impact H
body.overflow + pointerEvents gérés différemment à chaque modale — source de bugs (boutons non cliquables après fermeture).
→ Fix : _setModalOpen(true/false) centralisé
#3 — Modal open pattern dupliqué ×4 Impact H
backdrop.display + rAF double répété 4 fois avec légères variations — ~100 lignes dupliquées.
→ Fix : _openModal(backdropId, panelId) générique
#4 — Data attributes incohérents Impact M
data-tab, data-id, data-tx, data-item-id, data-loan-id mélangés sans convention stable.
→ Fix : standardiser sur data-item-id / data-loan-id
#5 — Z-index fragmentés Impact M
10, 200, 300, 390, 400, 490, 9999, 10000, 99999 sans échelle lisible.
→ Fix : --z-panel:400, --z-modal:9999, --z-toast:99999
#6 — Transitions incohérentes Impact M
0.12s, 0.15s, 0.22s, 300ms mélangés sans justification — parfois en secondes, parfois en ms.
→ Fix : --anim-fast:150ms, --anim-normal:300ms
#7 — btn-primary inline ×16 Impact M
Même cssText bouton vert recopié 16 fois — impossible à modifier globalement, ~400 lignes dupliquées.
→ Fix : classe .btn-primary en CSS global
#8 — Timeouts sans justification Impact M
40ms, 50ms, 80ms, 280ms, 300ms, 350ms mélangés arbitrairement — maintenance difficile.
→ Fix : DELAY_FOCUS=80, DELAY_ANIM=300 comme constantes nommées
#9 — Point orange .badge-dot inline ×5 Impact L
width:8px;height:8px;background:#F39C12;border-radius:50% recopié 5 fois dans le code JS.
→ Fix : classe .badge-dot ou constante DOT_HTML
#10 — fontSize hardcodée sans échelle Impact L
12/13/14/15/16/18/20px inline sans système de taille défini — cohérence fragile.
→ Fix : --text-xs:12px, --text-sm:13px, --text-base:15px, --text-lg:18px
